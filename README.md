# Student Performance Analyzer

An AI/ML project that explores student datasets, visualizes patterns, and compares machine learning models to analyze and predict student performance.

## Features

- Upload student datasets in CSV or Excel format
- Explore dataset structure and missing values
- Generate data summaries and visualizations
- Select suitable prediction targets
- Train and compare machine learning models
- Evaluate models using test metrics and cross-validation
- Download analysis results

## Technologies

- Python
- Streamlit
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn

## Run locally

1. Install Python.
2. Open a terminal in the project folder.
3. Create and activate a virtual environment.
4. Install dependencies:

   `pip install -r requirements.txt`

5. Start the application:

   `streamlit run app.py`

## Dataset

The application is designed to analyze uploaded datasets. `student-mat.csv` is included as a sample dataset.
